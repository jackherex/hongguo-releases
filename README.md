## 常见问题

**三个版本要装几个？**
各装各的。同一台设备装一个就行，装多了也不会互相影响。

**观看进度能同步吗？**
可以。三个版本都能在「设置」里配置设备互联或 WebDAV（坚果云、群晖、OpenList 都支持），
各设备填**同一套**配置即可。

**装完打不开、或者闪退？**
TV 版先确认位数选对了（见上面那节）；手机版确认系统是安卓 8.0 以上；
电脑版确认是 Windows 10 / 11 的 64 位系统。
